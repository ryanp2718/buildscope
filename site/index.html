PermitsResearchBot

An automated collector for an independent research project on residential building permits.

If you found this page in your server logs, this explains what the traffic is and how to stop it. You do not need to contact anyone to make it stop; see how to make it stop.

It is deliberately slow and light: one request at a time, at least 1.5 seconds apart on any one host, no retries, and a fixed cap on requests per run. It reads only public pages and backs off from anything that looks like a block.

What it is

A research crawler assembling a cross-jurisdiction dataset of residential building permits for economic research. The goal is measuring how permit issuance varies across jurisdictions over time. The Census Bureau's Building Permits Survey answers that question at an aggregate level; this dataset aims at finer resolution.

It reads the same public search pages a member of the public would. It does not attempt to authenticate, does not submit forms other than public record searches, does not follow links behind a login, and does not access anything a visitor could not reach in a browser.

The crawler's source is public at github.com/ryanp2718/buildscope; the fetching code is permits/capture.py.

How it behaves

User-AgentPermitsResearchBot/0.1 (municipal open-data coverage study; contact: https://ryanp2718.github.io/buildscope/)
Request rateOne request at a time. Minimum 1.5 seconds between requests to the same host; slower where robots.txt asks.
ConcurrencyNone. Single-threaded, one connection.
RetriesNone. A failed request is recorded and abandoned.
Volume ceilingA hard per-run request budget, counting robots.txt requests. The run aborts when it is reached rather than continuing.
robots.txtFetched once per host per run and honored. A group naming PermitsResearchBot takes precedence over *. A disallowed path is not requested.
ChallengesA bot challenge or interstitial is treated as a decline: recorded, not retried, and not worked around.

What it collects

Permit-level fields: record identifier, dates, permit type and work classification, dwelling unit counts, valuation, address, and jurisdiction. These are aggregated for statistical analysis.

Fetched pages are never published. Some permit pages show an individual's name next to a home address, for example on an owner-builder permit. The pages as fetched stay on the machine that fetched them and are not released in any form. The extracted dataset has no owner or applicant name field.

How to make it stop

Add this to your robots.txt and the crawler will stop on its next run, with no further action needed:

User-agent: PermitsResearchBot
Disallow: /

If you would prefer slower access to no access, a Crawl-delay in whole seconds is honored instead. It can only slow the crawler down; a value under 1.5 seconds has no effect.

User-agent: PermitsResearchBot
Crawl-delay: 10
